### 算法与模型的区别
- 算法：一系列确定性计算过程的组合的抽象。用来解决某类问题。
- 模型：对某个物理实体的描述和模拟。
> 因此，我认为两者不是同一个层次的概念。算法是抽象的，是解决一类问题的工
> 程方法，是问题导向的，其不关注具体的物理对象。而模型是具体的，描述的是
> 特定的物理过程，旨在模仿和理解物理对象的真实过程。不过现在的机器学习模
> 型一定程度上抛弃了可解释性，不过其仍是在模仿特定物理过程。
